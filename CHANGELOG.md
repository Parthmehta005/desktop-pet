# Changelog

Every notable change to Desktop Pet. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html): a new MAJOR version for
changes that break existing settings or behaviour, MINOR for new features, PATCH for
fixes.

## [Unreleased]

  join: Maple the blue panda, with a big bubbly ringed tail; Hum the bumblebee, whose

## [1.0.0] - 2026-11-27

The first release.

### Added
- Six pets to choose from, Mochi the cat, Biscuit the corgi, Pip the penguin, Axo the
  axolotl, Bolt the robot and Nimbus the soft care-bot, each with 19 animations, and a
  different pet every day if you like.
- A transparent, always-on-top strip along the taskbar where the pet walks about; clicks
  pass through everywhere except the pet, which you can pet, pick up and drop.
- Claude Code reactions through hooks: sweating while Claude works (more with several
  sessions), waving when Claude needs you, cheering when it finishes, and a "done" flag
  if it finished while you were away. Works with Claude Code on Windows and in WSL.
- Your activity: typing while you edit files in watched folders, confetti on commits,
  sleeping when you're idle or locked, a greeting when you're back, a stretch reminder
  and a bedtime nightcap.
- App moods on Windows: headphones for music, popcorn for videos, a controller for
  games, quiet during meetings, hidden over fullscreen apps, and rules you can edit.
- Low-battery panic: unplugged at 10% or less, the pet runs to the battery icon and
  points at it; a click opens Windows' battery settings.
- Quick hide and show with Ctrl+Alt+P or the tray.
- A settings window for everything, with changes applied as you make them.
- A Windows installer and a portable app, published on GitHub Releases with a link
  that always downloads the newest version; the version is shown in the tray menu and
  the settings window.
- A one-page guide (GUIDE.md), and a browser preview of every pet and animation.
